** Bucket-provisioning admin API (INTERNAL ONLY) **

  {{ printf "%s-admin" (include "common.names.fullname" .) }}.{{ include "common.names.namespace" . }}.svc.{{ .Values.clusterDomain }}:{{ .Values.bucketAdmin.service.port }}

  Create a tenant bucket pre-assigned to a cost tier (call from the control plane / BSS only):

    curl -X POST http://<admin-svc>:{{ .Values.bucketAdmin.service.port }}/buckets \
      -H "Authorization: Bearer <token>" \
      -d '{"name": "tenant-a-logs", "tier": 1}'

  WARNING: never expose this endpoint to tenants or the public. Keep the
  service ClusterIP and reachable only from trusted callers, and ensure
  tenant IAM policies exclude s3:CreateBucket / s3:DeleteBucket.
