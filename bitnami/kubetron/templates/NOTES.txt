PREREQUISITES on the cluster (kubetron is an orchestration layer, not a standalone CNI):
  - Multus CNI and ovs-cni (with the marker DaemonSet) installed and healthy.
  - OpenStack Neutron/Octavia reachable, and an admin application credential provided as
    the Secret named "{{ .Values.openstack.existingSecret }}" (envFrom keys: OS_AUTH_URL,
    OS_USERNAME/OS_PASSWORD or OS_APPLICATION_CREDENTIAL_*, OS_PROJECT_NAME, OS_PROJECT_DOMAIN_NAME, ...).
{{- if not .Values.openstack.existingSecret }}

  WARNING: openstack.existingSecret is empty. The manager has no OpenStack credentials and
  every NetworkPortClaim will fail. Set openstack.existingSecret (or provide the OS_* vars
  via extraEnvVars/extraEnvVarsSecret).
{{- end }}
{{- if .Values.webhook.certManager.enabled }}

    (serving certificates for the webhook{{ if .Values.apiserver.enabled }} and the aggregated apiserver{{ end }} are issued by cert-manager).

Enrol a workload by labelling its Pods (or the StatefulSet/VMI template) with:

    kubetron.network.kubevirt.io/enabled: "true"

and referencing a NetworkPortClaim. A minimal claim:

    apiVersion: kubetron.network.kubevirt.io/v1alpha1
    kind: NetworkPortClaim
    metadata:
      name: my-app
      namespace: {{ include "common.names.namespace" . }}
    spec:
      network: <neutron-network-name-or-id>
      credentialSecretRef: <tenant-app-credential-secret>

List claims with:

    kubectl get networkportclaims -A     # short name: npc
